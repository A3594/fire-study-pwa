# 소방 니모닉 카드

Logseq의 `화재안전기술기준`과 `점검실무행정/점검표` 페이지에서 문제와 니모닉만 추출해 만든 모바일 학습용 PWA입니다. Logseq 원문은 수정하지 않습니다.

## 학습 데이터 갱신

Logseq 내용을 수정한 뒤 프로젝트 상위 폴더에서 실행합니다.

```powershell
node .\fire-study-pwa\tools\build_cards.mjs
```

다른 Logseq 경로를 사용할 때는 `LOGSEQ_PAGES_DIR` 환경 변수를 지정할 수 있습니다.

## 로컬 실행

```powershell
python -m http.server 3217 --bind 0.0.0.0 -d .\fire-study-pwa
```

컴퓨터에서는 `http://127.0.0.1:3217/`로 확인합니다. 같은 와이파이의 휴대폰에서도 컴퓨터의 내부 IP와 `:3217`을 사용해 열 수 있지만, 홈 화면 설치와 오프라인 기능을 안정적으로 쓰려면 HTTPS 주소로 배포하는 것이 좋습니다.

## 학습 방식

- 문제를 먼저 보고 니모닉을 회상합니다.
- `니모닉 확인`을 누른 뒤 `다시 / 어려움 / 알겠음`으로 평가합니다.
- 평가한 카드의 진도는 즉시 저장되고, 다음 학습에서는 완료한 새 카드를 제외한 다음 순서의 카드가 출제됩니다.
- 학습 도중 앱을 종료하면 홈의 `저장된 학습 이어하기`에서 남은 카드부터 계속할 수 있습니다.
- 화재안전기술기준은 NFTC 번호 순서(소화기구 101부터), 점검표는 제목의 점검 번호 순서로 표시·출제됩니다.
- 과목을 선택하고 `선택 과목 반복 듣기`를 누르면 문제를 읽은 뒤 10초 후 니모닉을 두 번 읽고 다음 문제로 넘어갑니다.
- 반복 듣기는 마지막 문제 뒤에 처음부터 다시 재생되며, 일시정지·바로 답 듣기·다음 문제를 사용할 수 있습니다.
- 반복 듣기 과목·문제 위치·회차는 자동 저장되며, 앱을 다시 열어 `저장된 위치에서 이어 듣기`로 계속할 수 있습니다.
- 홈의 `불의 도서관과 첫 번째 소화마법`에서 NFTC 101의 기준을 사건과 대사에 녹인 연속 판타지 소설 1화를 들을 수 있습니다. 이야기 모드에는 별도의 회상시간이나 니모닉 재낭독이 없습니다.
- 1화는 해설·수지·태후 역할과 판타지 배경음을 합성한 약 22분의 장별 성우형 음성을 자동으로 이어 재생하며, 전체 연속본 MP3도 내려받을 수 있습니다.
- 2화 `옥내소화전의 붉은 수룡`은 NFTC 102의 수원·펌프·배관·송수구·전원·제어·배선·예외를 10개 장면의 현장계약과 로맨스로 연결합니다.
- 2화는 해설·수지·태후 역할과 판타지 배경음을 합성한 약 14분의 장별 성우형 음성을 자동으로 이어 재생하며, 전체 연속본 MP3도 내려받을 수 있습니다.
- 3화 `스파이더 히어로의 은빛 물거미망`은 NFTC 103의 방식·방호구역·배관·기동·헤드·송수구·전원·제외·드렌처를 10개 장면의 첫 특허 이야기로 연결합니다.
- 4화 `꼬마 물거미와 작은 가게`는 NFTC 103A의 설치대상·수원·가압방식·배관과 밸브 순서·관경·간이헤드를 9개 장면의 골목 안전사업으로 연결합니다.
- 1장은 해설·수지 역할·태후 역할의 AI 음성과 오리지널 판타지 배경음을 합성한 약 3분 11초짜리 성우형 샘플을 제공합니다. 2026-08-10부터 해설자와 수지는 같은 OpenAI `marin` 음성을 사용하며, 해설자는 차분하게 수지는 즐겁게 연기합니다.
- 샘플의 등장인물 음성은 실제 연예인이나 성우의 음성을 복제한 것이 아닌 일반 AI 생성 음성입니다.
- 이야기는 10개 장면을 자동으로 이어 읽고, 이전·다음·일시정지를 지원하며 종료한 장면 위치가 자동 저장됩니다.

### 이야기 장기 시간축

- NFTC 101~103: 태후 31세, 수지 30세. 창업과 연애 시작
- NFTC 103A~110: 32~34세. 소화설비 사업 확장과 동거가 아닌 건전한 연애
- NFTC 201~207: 35~38세. 약혼과 결혼
- NFTC 301~402: 39~44세. 자녀 출생과 중견기업 성장
- NFTC 501~505: 45~51세. 자녀의 학창시절과 전국 안전망 구축
- NFTC 602~609: 52~60세. 자녀가 성인이 되고 태후가 60세에 세계적 안전재벌 완성
- 로맨스는 포옹·키스·부부의 다정한 밤을 암시하는 수준으로만 표현하고 노골적인 성행위는 묘사하지 않습니다.
- 수지는 실존 인물과 무관한 성인 가상 인물이며, 외모 묘사와 함께 기술 판단·사업 기여·주도적인 선택을 균형 있게 다룹니다.
- 이야기 속 인물과 사건은 학습을 위한 완전한 허구이며 실제 인물·사건과 무관합니다.
- 학습 진도는 현재 브라우저의 로컬 저장소에만 저장됩니다.
- 답안 전문과 이미지는 표시하지 않습니다.
